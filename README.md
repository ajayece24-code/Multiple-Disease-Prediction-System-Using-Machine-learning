# Multiple Disease Prediction System Using Machine Learning

A web-based Multiple Disease Prediction System developed using **Machine Learning and Django**. The application predicts the possibility of diseases based on health parameters entered by the user.

## 📌 Project Overview

The Multiple Disease Prediction System is designed to provide an easy-to-use platform where users can enter their medical parameters and receive a disease prediction generated by a trained machine learning model.

The system integrates a machine learning model with a Django-based web application to provide predictions through a simple and interactive user interface.

## 🚀 Features

- Machine Learning-based disease prediction
- User-friendly web interface
- User registration and login
- Health parameter input form
- Real-time prediction results
- Django backend integration
- Trained ML model using `.pkl` files
- Responsive web pages
- Chatbot interface
